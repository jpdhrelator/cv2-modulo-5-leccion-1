Vas a aplicar todo lo visto en clases sobre Programación Orientada a Objetos en JavaScript. No es copiar los ejemplos de clase — son escenarios nuevos que requieren que pienses y apliques los conceptos.

  • Puedes ver los pistas, pero no hay soluciones — piensa primero

La Clase Círculo

Escenario: una app de geometría necesita modelar círculos
class constructor getter static
Estás construyendo una herramienta de geometría. Necesitas representar un círculo con sus cálculos principales. Un círculo se define únicamente por su radio.

Lo que debes implementar

  • Clase Circulo con un constructor que reciba el radio El radio es el único dato necesario para definir un círculo
  • Getter diametro que retorne el doble del radio Debe accederse sin paréntesis, como si fuera una propiedad
  • Método area() que calcule y retorne el área del círculo Fórmula: π × radio²
  • Método perimetro() que calcule y retorne la circunferencia Fórmula: 2 × π × radio
  • Método toString() que retorne una descripción en texto del círculo con sus medidas redondeadas a 2 decimales
  • Método estático elMasGrande(c1, c2) que reciba dos círculos y retorne el que tiene mayor área ¿Por qué este método va en static y no en la instancia?
  • Prueba: crea al menos 3 círculos distintos, guárdalos en un array, imprímelos todos con toString() y luego imprime cuál tiene el mayor área
Salida esperada (ejemplo)
Círculo(radio=5) → área: 78.54 | perímetro: 31.42 | diámetro: 10
Círculo(radio=3) → área: 28.27 | perímetro: 18.85 | diámetro: 6
Círculo(radio=8) → área: 201.06 | perímetro: 50.27 | diámetro: 16
El más grande es: Círculo(radio=8)
💡 Pista — si estás atascado
  • JavaScript tiene Math.PI disponible nativamente — no necesitas declararlo.
  • Para redondear a 2 decimales, el método .toFixed(2) existe en todos los números. Retorna un string.
  • Un método static se llama sobre la clase, no sobre un objeto. Piensa: Circulo.elMasGrande(c1, c2)
  • Para encontrar el mayor en un array de más de 2, Array.reduce() es tu amigo.

Inventario de una Tienda

Escenario: un pequeño negocio necesita gestionar sus productos
class instancias arrays
Una tienda de ropa necesita un sistema básico para gestionar su inventario. Cada producto tiene datos propios pero todos comparten la misma lógica de negocio.

Lo que debes implementar

  • Clase Producto con: nombre, precio, stock, categoria
  • Método hayStock() que retorne true si el stock es mayor a cero
  • Método aplicarDescuento(porcentaje) que modifique el precio según el descuento Valida que el porcentaje esté entre 0 y 100, si no lo está imprime un error
  • Método vender(cantidad) que descuente del stock. Si no hay suficiente stock, no vende y avisa
  • Método toString() con una descripción completa del producto
  • Prueba con un inventario real: crea al menos 5 productos distintos con diferentes categorías. Luego: ① Filtra e imprime solo los que tienen stock · ② Ordénalos de menor a mayor precio · ③ Aplica 20% de descuento a todos los de la categoría "ropa" · ④ Imprime el precio promedio del inventario
💡 Pista — si estás atascado
  • Array.filter() retorna un nuevo array con los elementos que cumplan la condición.
  • Array.sort((a, b) => a.precio - b.precio) ordena de menor a mayor.
  • Para el promedio, primero suma todos los precios con reduce(), luego divide por la cantidad.
  • Para filtrar por categoría antes de aplicar el descuento, puedes encadenar filter().forEach().

Tu Perfil de Desarrollador/a

Escenario: crea tu propio perfil como si fuera una tarjeta de presentación
objeto literal métodos
Usando un objeto literal (sin clase), modela tu propio perfil de desarrollador/a. Este ejercicio es personal — los datos son tuyos.

Lo que debes implementar

  • Objeto literal miPerfil con al menos estas propiedades: nombre, edad, ciudad, lenguajes (array), añosDeExperiencia, buscandoTrabajo (boolean)
  • Método presentarse() que genere e imprima una presentación completa usando template literals
  • Método agregarLenguaje(lenguaje) que agregue un lenguaje al array y confirme que fue agregado Verifica primero que el lenguaje no esté ya en el array
  • Método nivelExperiencia() que retorne "Junior", "Semi-Senior" o "Senior" según los años de experiencia (tú defines los rangos)
  • Recorre e imprime todas las propiedades que no sean funciones
  • Bonus: Agrega 2 lenguajes nuevos con el método y luego imprímelos. Intenta agregar uno que ya existe y verifica que no se duplique.
💡 Pista — si estás atascado
  • Para revisar si un elemento ya existe en un array: array.includes(valor) retorna true o false.
  • Para recorrer propiedades: for (const clave in objeto) y dentro filtrar con typeof objeto[clave] !== "function".
  • Los template literals con backticks `` ` `` permiten saltos de línea reales — útil para presentaciones multilínea.

Flota de Vehículos

Escenario: una empresa de arriendo necesita modelar su flota
extends super herencia
Una empresa de arriendo de vehículos tiene autos, motos y camiones. Todos comparten características comunes, pero cada tipo tiene sus propias particularidades. Modela esta jerarquía usando herencia.

Lo que debes implementar

  • Clase base Vehiculo con: marca, modelo, año, velocidadMaxima Método describirse() que imprima la información básica · Método calcularAntiguedad() que retorne cuántos años tiene el vehículo
  • Clase Auto extends Vehiculo con: numeroPuertas, tipoCombustible Sobreescribe describirse() para que incluya las puertas y el combustible, pero también muestre la info del padre (usa super.describirse())
  • Clase Moto extends Vehiculo con: tieneCarrito (boolean) Sobreescribe describirse() indicando si tiene carrito lateral o no
  • Clase Camion extends Vehiculo con: capacidadToneladasMaxima Sobreescribe describirse() indicando la capacidad de carga
  • Crea una flota de al menos 6 vehículos mezclando los tres tipos. Luego: ① Imprime la descripción de cada uno · ② Filtra e imprime solo las motos · ③ Calcula la velocidad máxima promedio de toda la flota · ④ Encuentra el vehículo más antiguo
💡 Pista — si estás atascado
  • super(marca, modelo, año, velocidadMaxima) en el constructor hijo llama al constructor del padre — es obligatorio antes de usar this.
  • super.describirse() dentro de un método sobreescrito ejecuta la versión del padre. Luego puedes agregar más info específica del hijo.
  • Para filtrar por tipo: flota.filter(v => v instanceof Moto)
  • El año actual en JS: new Date().getFullYear()

Figuras Geométricas Polimórficas

Escenario: una app de dibujo necesita calcular el área de cualquier figura
polimorfismo override extends
Una aplicación de dibujo vectorial maneja distintos tipos de figuras. El sistema necesita poder calcular el área de cualquier figura sin importar qué tipo sea — solo llamando al mismo método.

Lo que debes implementar

  • Clase base Figura con: color Método area() que lance un error: throw new Error("area() debe implementarse en cada figura") — así obligamos a las subclases a sobreescribirlo
  • Método describir() en Figura que imprima el tipo, color y área — este método puede llamar a this.area() internamente Si cada subclase tiene su propio area(), ¿qué imprimirá describir() para cada una?
  • Clase Triangulo extends Figura con: base, altura Sobreescribe area() con la fórmula correcta: (base × altura) / 2
  • Clase Rectangulo extends Figura con: ancho, alto Sobreescribe area()
  • Clase Circulo extends Figura con: radio Sobreescribe area()
  • Crea un canvas: un array con al menos 6 figuras mezcladas. Itera con forEach y llama describir() en cada una. Al final, calcula e imprime el área total de todas.
💡 Pista — si estás atascado
  • El método describir() del padre llama this.area(). Cuando se ejecuta en una instancia de Triangulo, JS busca area() en Triangulo primero. Eso es exactamente el polimorfismo en acción.
  • Para el área total: canvas.reduce((suma, figura) => suma + figura.area(), 0)
  • Para saber el nombre del constructor de un objeto en tiempo de ejecución: objeto.constructor.name

Carrito de Compras Encapsulado

Escenario: un e-commerce necesita un carrito con lógica protegida
#private getter encapsulamiento
Un carrito de compras tiene reglas de negocio claras: no se puede modificar el total directamente, los ítems solo se agregan o eliminan por métodos controlados, y los cupones de descuento deben validarse. Implementa esto con encapsulamiento real.

Lo que debes implementar

  • Clase Carrito con dos campos privados: #items (array vacío) y #descuento (número, empieza en 0)
  • Getter total que calcule la suma de todos los ítems aplicando el descuento Cada ítem tiene nombre, precio y cantidad. Total = (suma de precio × cantidad) × (1 - descuento/100)
  • Getter cantidadItems que retorne cuántos ítems distintos hay en el carrito
  • Método agregar(nombre, precio, cantidad = 1) Valida que precio sea mayor a 0 y cantidad sea al menos 1. Si el producto ya existe (mismo nombre), suma la cantidad en vez de agregar uno nuevo.
  • Método eliminar(nombre) que remueva el ítem del carrito. Si no existe, avisa.
  • Método aplicarCupon(codigo) que aplique descuento según el código: "CLASE2026" → 20% · "MITAD" → 50% · cualquier otro → sin descuento, imprime mensaje de error
  • Método verResumen() que imprima todos los ítems con su subtotal, el descuento aplicado y el total final
  • Prueba: agrega 4 productos, aplica un cupón, elimina uno, intenta agregar uno con precio negativo, imprime el resumen
💡 Pista — si estás atascado
  • Para buscar si un ítem ya existe: this.#items.find(item => item.nombre === nombre) — si existe, modifica su cantidad directamente.
  • Para eliminar: this.#items = this.#items.filter(item => item.nombre !== nombre)
  • En el getter total, usa reduce para sumar precio × cantidad de cada ítem, luego aplica el descuento al resultado final.
  • Campos privados con # requieren Chrome/Firefox moderno o Node 12+.

Proyecto Final · Ejercicio 7

Sistema de Gestión
de una Librería

Este proyecto integra todos los conceptos de la lección: clases, herencia, polimorfismo, encapsulamiento y JSON. No hay un guión paso a paso — debes diseñar el sistema tú mismo/a siguiendo los requisitos.
class + constructor extends + super polimorfismo #encapsulamiento JSON.stringify JSON.parse arrays + métodos
Una librería independiente quiere digitalizar su gestión. Necesita un sistema que represente su colección de libros (físicos, digitales y enciclopedias), permita préstamos y devoluciones, y pueda exportar e importar su catálogo como JSON para compartir entre sucursales.

Arquitectura de clases que debes implementar

Clase base
Libro
  • titulo: string
  • autor: string
  • año: number
  • paginas: number
  • isbn: string
  • get edadEnAnios()
  • esAntiguo(): boolean
  • resumen(): string
Hereda de Libro
LibroDigital extends Libro
  • formatoArchivo: string
  • tamañoMB: number
  • ↑ hereda todo de Libro
  • resumen() [override]
  • tiempoDeLectura(ppm)
Hereda de Libro
Enciclopedia extends Libro
  • volumen: number
  • tematica: string
  • ↑ hereda todo de Libro
  • resumen() [override]
Clase con encapsulamiento
Biblioteca
  • #coleccion: Libro[]
  • #prestamos: string[] (isbns)
  • get totalLibros()
  • get librosPrestados()
  • agregar(libro)
  • prestar(isbn)
  • devolver(isbn)
  • buscarPorAutor(autor)
  • buscarPorTipo(Clase)
  • exportarCatalogo(): string JSON
  • static importarDesdeJSON(json)
  • generarReporte()

Requisitos de las clases

  • Libro — clase base. El getter edadEnAnios calcula cuántos años tiene desde su publicación. esAntiguo() retorna true si fue publicado antes del año 2000. resumen() retorna un string con toda la info del libro.
  • LibroDigital — sobreescribe resumen() para incluir formato y tamaño. Agrega tiempoDeLectura(palabrasPorMinuto = 250) que estime las horas de lectura (asume 300 palabras por página).
  • Enciclopedia — sobreescribe resumen() para incluir el volumen y la temática.

Requisitos de Biblioteca

  • agregar(libro) — valida que el parámetro sea una instancia de Libro (usa instanceof). Si no lo es, lanza un error.
  • prestar(isbn) — mueve el isbn a #prestamos. Si ya está prestado o no existe, avisa. No puede prestarse dos veces.
  • buscarPorTipo(Clase) — ej: biblioteca.buscarPorTipo(LibroDigital) retorna todos los libros de ese tipo.
  • exportarCatalogo() — retorna un string JSON con todos los libros de #coleccion.
  • static importarDesdeJSON(json) — parsea el JSON, crea instancias de Libro básicas y retorna una nueva Biblioteca con esos libros.
  • generarReporte() — imprime: total libros, cuántos prestados, cuántos por tipo, el más antiguo y el más nuevo.

Script de prueba que tu código debe poder ejecutar

  • Crea una instancia de Biblioteca
  • Agrega al menos 8 libros mezclando los 3 tipos (mínimo 3 de cada tipo base, 2 digitales, 2 enciclopedias)
  • Intenta agregar algo que no sea un libro y verifica que falle correctamente
  • Presta 3 libros distintos por isbn
  • Devuelve 1 de los prestados e intenta prestar el mismo dos veces
  • Busca todos los libros de un autor específico e imprímelos
  • Busca todos los LibroDigital y para cada uno imprime el tiempo estimado de lectura
  • Llama a exportarCatalogo(), guarda el resultado en una variable e imprímelo
  • Usa ese JSON para crear una nueva biblioteca con importarDesdeJSON() e imprime su total de libros
  • Genera el reporte completo de la biblioteca original
💡 Pista — orientación general (no es la solución)
  • Diseña antes de codear. Dibuja en papel las 4 clases, sus propiedades y relaciones. ¿Qué hereda quién? ¿Qué es privado?
  • exportarCatalogo() puede ser tan simple como JSON.stringify(this.#coleccion) — recuerda que stringify no incluye métodos, solo datos.
  • En importarDesdeJSON(), parseás con JSON.parse() y luego mapeas cada objeto a un new Libro(...). No podrás recrear LibroDigital o Enciclopedia sin guardar el tipo en el JSON — eso es un problema interesante de diseño.
  • Para el tiempo de lectura: páginas × 300 palabras / palabrasPorMinuto = minutos. Convierte a horas y minutos para mostrarlo bien.
  • El método generarReporte() puede usar buscarPorTipo() internamente — no dupliques lógica.
